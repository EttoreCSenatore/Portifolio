Confere

Security · Open source

Check before you pay. A web app, API and command-line tool that cross-reference public Brazilian data from BrasilAPI (company CNPJ, banks, Pix participants) and show explained warning signs, without storing what you look up. Built privacy-first, with LGPD (Brazil's data protection law) in mind from the first commit.

  • Explainable risk rules: every sign shows the rule and weight behind it; a hint, never a verdict, and it does not verify the Pix key holder
  • Privacy by design, enforced by tests: no accounts or history, and no IPs or identifiers in logs; sole proprietors and MEI have their name and address omitted
  • Open-data explorer with CSV export that works from a weekly local copy of the public lists, so it does not depend on BrasilAPI for them
  • Non-root read-only Docker + Caddy deployment, strict CSP, Trivy, gitleaks and SBOMs in CI, a smoke test that checks the logs; AI-assisted LGPD review (not legal advice)
  • FastAPI + React + Typer CLI with 160+ automated tests; bilingual Docusaurus docs (English and Português), AGPL-3.0

Atalaia

Security · Open source

An open-source, self-hosted network watchtower, in the spirit of Fing: discover the devices on your network, keep their history, get alerts and run defensive security checks. A single Go binary on the LAN that serves its own web app. Atalaia is Portuguese for watchtower.

  • Released as v0.5: device discovery and history, a Svelte web app with login, alerts through ntfy, Telegram, webhook and e-mail, Docker image and .deb/.rpm packages for amd64, arm64 and armv7
  • Identifies devices by mDNS, SSDP/UPnP, NetBIOS and DHCP names, with a type guess (router, printer, TV, camera, phone...) and icons on the dashboard
  • Defensive checks without root: ARP-spoofing signs, rogue DHCP server detection, exposed-service and TLS audit, plus ping, DNS, traceroute, port scan, Wake-on-LAN and a speed test
  • Safe by design: scope locked to the host's own private networks, active actions opt-in, admin-only and logged, built-in HTTPS, hardened systemd unit; no exploitation tools and no telemetry on purpose
  • Release pipeline with checksums, SBOM and provenance; gosec and govulncheck in CI; bilingual documentation (English and Português), AGPL-3.0
