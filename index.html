02 Projects

Sentinela do Fogo

Open source

Wildfire early-warning for Brazil. Combines INPE satellite hotspots, the FMA+ fire-danger index computed from Open-Meteo weather, and optional ESP32 sensor nodes, then routes alerts to landowners, fire brigades and Defesa Civil over Telegram, WhatsApp, SMS or webhooks.

  • FastAPI backend with MQTT ingest, risk engine and SSE live updates
  • React + Leaflet dashboard, PlatformIO firmware, Docker Compose stack
  • Bilingual Docusaurus docs (English and Português), CI on every push
  • Python
  • FastAPI
  • React
  • MQTT
  • ESP32
  • Docker

SlicePizza

DevOps lab

A hands-on DevOps learning project, built with a small team: an online ordering system for a fictional pizzeria that grows in phases, each one forcing a new technology to be learned by feeling the problem first.

  • Shipped: FastAPI orders API on PostgreSQL, menu site and Caddy on one domain, kitchen board behind a login
  • Order events through RabbitMQ (outbox) to a Telegram notification worker; container images built in CI
  • Next phases: observability, Terraform and Kubernetes (k3s)
  • FastAPI
  • PostgreSQL
  • Docker
  • Caddy
  • RabbitMQ
  • GitHub Actions
